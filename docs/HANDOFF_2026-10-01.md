## 7. 중요한 보존 원칙

- Session state persists across module/reference navigation.
- WebGL renderer/viewer lifecycle does NOT persist across module exits. Viewer dispose/context release를 유지한다.
- Explicit reset deletes learning state; “측정값 모두 지우기”의 의미와 모듈 격리를 유지한다.
- Reaction Energy minimum barrier guard(5 kJ·mol⁻¹)와 dynamic reduction maximum을 유지한다.
- Catalyst does not change ΔG/equilibrium; 정·역방향 장벽을 함께 낮춘다. 반응 좌표는 시간축이 아니다.
- Km != Kd. 기질 축0–600, 두 곡선 shared y-axis, axis expansion 설명, high-Km range-limit 경로를 유지한다.
- Virtual measurement is deterministic model output; 동일 조건 1점 / 독립 반복·실험 원자료와 구분한다.
- Mobile SectionJumpButton flow, focus/scroll/reduced-motion 분기와 desktop/tablet 기존 배치를 유지한다.
- Graph readability improvements와 SVG/3D label 충돌·clipping 방지를 유지한다.
- Regulation one-protein/two-activity model, 간 isoform 범위, 상대 활성/실제 flux 구분을 유지한다.
- Ser33 schematic vs actual 1K6M coordinates distinction을 유지한다.
- 3D 확대/닫기에서 same canvas/context reuse, camera/selection/summary 유지와 정상 cleanup을 보존한다.
- Reference direct section navigation, TOC replace-history 정책, 핵심 한계/상세 metadata와 명시적 복귀를 유지한다.
- Dialog focus return과 disabled/missing trigger/route-unmount fallback을 유지한다.
- Skip link / route title policy를 유지한다. Rail focus는 유지하고, 명시적 section/복귀는 해당 heading/main으로 이동한다.

## 8. 집에서 시작할 때 확인할 것

**집 PC에 기존 local change가 있으면 아래 pull 전에 중단하고 그 change부터 확인한다.** 첫 status가 깨끗할 때만 fetch/switch/pull을 진행한다. 자동 stash/reset/merge/rebase를 하지 않는다. `--ff-only`가 실패하면 강제로 진행하지 말고 local/remote history부터 확인한다.

```powershell
Set-Location "<집 PC의 enzyme-explorer repository 경로>"
git status --short --branch
# 위 status에 local change가 있으면 여기서 중단하고 확인
git fetch origin
git switch main
git pull --ff-only origin main
git log -1 --oneline

# node_modules가 없거나 dependency 설치가 필요한 경우에만
npm ci

npm test
npm run typecheck
npm run lint

# package.json의 실제 dev script: vite --host 127.0.0.1
npm run dev
```

Node engine은 `>=22.12.0`이다. 개발 서버가 출력하는 URL에서 `/enzyme-explorer/`를 연다. 기본 포트가 사용 중이면 실제 출력된 포트를 따른다. 5개 browser fixture는 `/enzyme-explorer/tests/browser/{session,phase-a2,readability,mobile-experiment,navigation-context}-harness.html`이며 각 HTML/TSX가 versioned다.

Local-only 제외 목록은 다음과 같다. 삭제하지 않았다.

| 경로 | 분류 / 이유 |
|---|---|
| `node_modules/` | 로컬 dependency 설치 산출물. 필요한 경우 `npm ci`로 재현 |
| `dist/` | build 산출물. `npm run build`로 재현 |
| `.claude/launch.json` | 학교 PC의 고정 preview 포트 설정. `.gitignore`의 의도된 local-only 설정이며 집에서 `npm run dev`에 필요 없음 |

집에서 필요한 source/test/doc/fixture/evidence를 untracked 또는 unstaged로 남기지 않는 것을 마감 조건으로 삼는다. Push 뒤 clean `main...origin/main`과 원격 main SHA 일치를 최종 완료 보고에서 확인한다. 배포 완료는 이 handoff의 필수 조건이 아니다.
